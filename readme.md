# 🚚 Fletes Bauti y Papá

Juego en 3D estilizado desarrollado con Three.js donde controlas a **Bauti** (con su buzo marrón, rulos y mochila) ayudando a su papá con la mudanza y el camión azul de fletes.

## 🕹️ Controles
* **WASD / Flechas**: Mover a Bauti o conducir el camión.
* **Tecla E**: Levantar o soltar muebles en el camión azul.
