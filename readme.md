# 🚚 Fletes Bauti y Papá (Estilo Roblox)

Un juego en 3D desarrollado con Three.js inspirado en Roblox, donde controlas a **Bauti** (con su característico buzo marrón, rulos y mochila) ayudando a su papá a cargar y trasladar muebles en un camión azul.

## 🎮 Controles del Juego

### Fase 1: Cargar el Camión
* **W, A, S, D**: Mover a Bauti.
* **Tecla E**: Levantar o dejar muebles dentro del camión azul.

### Fase 2: Manejar el Camión
* **W / S**: Acelerar y frenar / marcha atrás.
* **A / D**: Girar el camión a la izquierda o derecha.
